Found while checking

  • Google's email-signing key (DKIM) is published on the bare domain instead of google._domainkey, so outgoing company mail most likely fails DKIM. Phase 4 fixes it.
  • The registrar's record for the domain changed on October 6 at 14:11 UTC. If the owner's name or email was changed recently, a transfer lock of up to 60 days can apply.
  • DNSSEC is off today, so the nameservers can change without an extra step.

2Point DNS at Cloudflare

The domain stays registered at SiteGround for now. Only the nameservers change, so Cloudflare answers for the domain. Copy the records first and email keeps working throughout.

Cloudflare loginSiteGround login

  1. Cloudflare dashboardOnboard a domainolinnsecurityinc.comFree

    Let it scan for existing records. Cloudflare notes the scan can miss some, which the next step catches.

  2. Check each row against the records table. Add anything missing, delete anything the scan invented, and switch the proxy off on the website records.

  3. Email Routing breaks Google mail here. It adds Cloudflare's own MX records for its forwarding service. This domain must keep only the five Google MX records. If Cloudflare offers to set up Email Routing, decline.

  4. Client AreaServicesDomainsSettingsNameservers

  5. This usually takes minutes and can take up to 24 hours. Leave the SiteGround DNS zone untouched for 48 hours afterwards: some networks keep asking the old nameservers that long.

3Transfer the domain to Cloudflare

Start once Cloudflare shows Active. Submit before November 1 for the current price; it must complete before November 23. The transfer adds one year, so the domain will expire November 23, 2027.

SiteGround loginCloudflare login

  1. Client AreaServicesDomainsSettings⋮ menuRegistrar Lock

  2. DomainsSettings⋮ menuGet EPP Code

    Treat the code like a password. Anyone holding it can move the domain. Paste it straight into Cloudflare; do not send it by email or chat. It is case-sensitive, so copy it without spaces.

  3. Cloudflare dashboardDomain RegistrationTransfer Domains

  4. SiteGround or eNom may email the owner's address asking to approve. Approving speeds it up; otherwise it completes on its own, usually within 5 days and at most 10.

    Keep SiteGround's auto-renew on until the transfer completes. If the transfer fails, the domain must not lapse on November 23.

  5. Today
    whois olinnsecurityinc.com | grep -iE "registrar:|expiry"

Registrar: eNom, LLC
    After the transfer
    whois olinnsecurityinc.com | grep -iE "registrar:|expiry"

Registrar: Cloudflare, Inc.

  6. Cloudflare dashboardDNSSettingsEnable DNSSEC

    With Cloudflare as both registrar and DNS host, this is one click. It protects visitors and mail servers from forged DNS answers.

5Launch the new website

Each step here needs the owner's go-ahead. It follows the Cutover checklist in the project's launch notes (docs/LAUNCH.md), including the form tests and redirect decisions listed there.

Owner approvalDeveloperCloudflare login

  1. Vercelo-linn-website-v4SettingsDomains

  2. Edit A @ (today 35.215.81.195) and CNAME www to Vercel's values. Keep both DNS only. Do not touch the MX or TXT records.

  3. Copy exactly what the domain's Records tab in Resend shows: a DKIM TXT at resend._domainkey and the return-path records on send. None of them touches the Google MX or SPF records.

  4. Cloudflare dashboardTurnstileAdd widget

    Hostname olinnsecurityinc.com, mode Managed. Give the site key and secret key to the developer to store in Vercel's settings as TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY; never paste them into email or chat.

  5. Developer, from the project folder
    node scripts/verify-launch.ts https://olinnsecurityinc.com --indexed --forms

    It checks indexing, security headers, every redirect, both form endpoints and the www redirect. Then send one real test through each form.

6Close the SiteGround account

Last, and only once every condition below holds.

SiteGround loginCloudflare login
Before cancelling, all four must be true:
  • The new website is live on Vercel and the launch check passed.
  • The WordPress content and its media are backed up.
  • Google bills Workspace directly (Phase 1, or Phase 0 found it already did).
  • Cloudflare is the registrar (Phase 3 verified).
    • WordPress admin › Tools › Export › All content. Save the file.
    • Site Tools › Site › File Manager: download wp-content/uploads. It holds the 58 images (gallery, founder, team, onboarding) that are not on the new site.

  2. Remove mail, ftp and autodiscover (A records to 35.215.81.195) and the SRV record _autodiscover._tcp. They point at the server being cancelled.

  3. Client AreaServicesHosting

    Cancelling deletes the old site's files. It cannot be undone, so confirm the backup opens first. Afterwards, check the Client Area for anything still set to renew (domain, Workspace) and turn it off.

Why Cloudflare, and what it costs

The reasoning

  • The registrar saves about $9 a year. The real saving is ending SiteGround hosting once the new site is live.
  • Keeping the domain apart from the website host means a future website move never touches email.
  • Turnstile works with any DNS provider, so it is not a reason by itself, but one Cloudflare account for all three keeps logins in one place.
